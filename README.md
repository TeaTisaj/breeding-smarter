# Breeding Smarter

**A data-driven matching system for genetic diversity in dogs and beyond.**

![CI](https://img.shields.io/badge/CI-pending-lightgrey)

> **Synthetic data notice.** Every animal, kennel, registration number and microchip in this
> project is synthetic. Nothing here describes a real dog. Results are in-silico.

Kennel clubs today have lookup tools (what is this dog's COI?), not decision tools (which mate
best protects this breed?). Breeding Smarter is an open, explainable, rule-aware matching engine
plus a calibrated synthetic pedigree benchmark that proves it works.

## Quickstart

```bash
uv sync --all-groups
uv run bsm --help
```
